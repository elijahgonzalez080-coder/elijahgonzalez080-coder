This is a time domain transient simulation project that I put together in LTSpice to analyze how a common source amplifier circuit responds to a square wave input signal. For the power source I configured a pulse voltage generator to produce a clean square wave with an amplitude of 25 millivolts and a total period of 5 microseconds. The signal travels through a 50 ohm input resistor and passes into a filtering network made of two 20 picofarad capacitors labeled C1 and C2 which represent the internal capacitance values at the gate and drain nodes of the amplifier.

Instead of using a standard physical transistor model I built the core of the amplifier using a voltage dependent current source with a transconductance value set to 0.01 Siemens. This setup models the amplifying behavior of the circuit by pulling current down based on the voltage drop across the gate and source terminals. On the output side I wired up a 4000 ohm load resistor in parallel with a 200 picofarad capacitor and an extra 12 picofarad capacitor to simulate the real world output loading constraints. I added a transient simulation command at the bottom to run the test for a total duration of 20 microseconds which gives the tool enough time to capture exactly how the output voltage at node out stabilizes over multiple full cycles of the square wave.
