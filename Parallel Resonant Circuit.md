This is an advanced circuit simulation project that I set up in LTSpice to analyze a parallel resonant tank circuit using parameter sweeping techniques. The circuit is driven by an AC voltage source configured to output a clean sine wave at a fixed frequency of 125 kilohertz. The source voltage travels through a 10K ohm resistor which creates a voltage divider network when paired with the parallel combination of the inductor and capacitor below it. By wiring the inductor and capacitor directly in parallel with each other I created a resonant tank filter that is designed to capture and react to that specific target frequency.

To make the simulation much more dynamic than a basic run I used specialized SPICE commands to automate the component values. I set up a step parameter command for the capacitor to automatically sweep its value from 2 nanofarads up to 50 nanofarads in increments of 2 nanofarads. Then instead of hardcoding a fixed value for the inductor I used a mathematical equation statement to automatically recalculate the exact required inductance value for every single step of the capacitor sweep so the tank circuit stays perfectly tuned to 125 kilohertz every time. Since these are ideal components without any internal parasitic losses the transient command at the bottom will run a detailed time domain analysis to show exactly how the voltage peaks scale during resonance across all the different component combinations.
